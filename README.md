Chat17 💬

Chat17 is a simple, modern, real-time chat application designed for fast and private room-based conversations.

Users can create or join chat rooms using a unique room code and communicate in real time across mobile and desktop devices.

---

✨ Features

- 💬 Real-time messaging
- 🔐 Room-based conversations
- 🔑 Create and join rooms using room codes
- 📱 Responsive mobile design
- 💻 Desktop-friendly interface
- ☀️ Light mode
- 🌙 Dark mode
- 🔄 Automatic reconnection and room rejoin
- 🔔 Unread message count
- 🆕 New-message indicator
- 👁️ Message seen/read tracking
- 🟢 Online user presence
- ↩️ Reply to messages
- 👆 Swipe-to-reply on mobile
- 🗑️ Delete your own messages
- ✏️ Personal/favourite room names
- ⋮ Room actions menu
- 🗑️ Delete rooms
- 📷 QR-based room sharing
- 📱 Mobile bottom navigation
- 👤 Profile section
- 🎨 Clean responsive UI
- 🔒 Account/logout confirmation
- 🔎 SEO metadata

---

🔄 Real-Time Communication

Chat17 uses Socket.IO to provide real-time communication between connected users.

Messages can be delivered between users without manually refreshing the page.

The application also supports:

- Automatic reconnection
- Room rejoin after connection interruption
- Real-time message updates
- Online presence updates

---

🏠 Chat Rooms

Users can create or join rooms using a unique room code.

Typical Flow

1. Enter your name.
2. Create a new room or join an existing room.
3. Share the room code or QR code.
4. Start chatting in real time.

---

↩️ Message Replies

Chat17 supports replying to specific messages.

On mobile devices, users can also use a swipe-to-reply interaction inspired by modern messaging applications.

---

🔔 Unread Messages

Chat17 keeps track of unread messages and displays an unread count when new messages arrive.

A New Messages indicator helps users identify where new messages begin in the conversation.

---

👁️ Seen Messages

Messages support read/seen tracking so users can identify when messages have been viewed.

---

🟢 Online Presence

Chat17 displays online presence information for users connected to a chat room.

---

📷 QR Room Sharing

Rooms can be shared using QR codes.

This makes it easier for another user to join a room without manually entering the complete room code.

🚀 Running Locally

1. Clone the Repository

git clone https://github.com/subash-1701/chat17.git

2. Open the Project

cd chat17

3. Install Dependencies

npm install

4. Start the Application

node index.js

5. Open in Your Browser

http://localhost:3000

🌐 Deployment

Chat17 can be deployed to a Node.js-compatible hosting platform.

After deployment, users can access the application through the deployed URL and create or join chat rooms.

🔒 Privacy

Chat17 is designed around room-based conversations.

Users communicate through specific chat rooms rather than a traditional global chat feed.
